# StageNow-ZebraFinder

Öffentliches Distribution-Repository für ZebraFinder.

Dieses Repository wird ausschließlich für die Bereitstellung der signierten ZebraFinder-APK über Zebra StageNow verwendet.

## Inhalt

- Zebrafinder.apk
- CHANGELOG.md
- LICENSE.txt

## Verwendung

Die APK wird durch StageNow direkt aus diesem Repository geladen.

Raw-URL:

https://raw.githubusercontent.com/IT-Espas/StageNow-ZebraFinder/refs/heads/main/Zebrafinder.apk

## Hinweis

Der Quellcode von ZebraFinder ist nicht Bestandteil dieses Repositories.

ZebraFinder ist proprietäre Software für den internen Einsatz bei ESPAS. Eine externe Nutzung, Weitergabe oder Bereitstellung ist nicht gestattet.

Siehe LICENSE.txt.
